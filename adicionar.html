Como adicionar um novo layout

Siga os passos abaixo para colocar seu HTML na galeria

1

Coloque o arquivo na pasta layouts

Envie o seu arquivo .html para a pasta layouts/ do projeto.

  • No Netlify: faça um novo deploy arrastando a pasta atualizada
  • No GitHub: entre na pasta layouts → Add file → Upload files
2

Edite o arquivo index.html

Abra o index.html e procure a seção dos cards. Adicione um novo card copiando o modelo abaixo:

<a href="layouts/SEU-ARQUIVO.html" class="card" target="_blank"> <div class="card-preview"> <div class="preview-placeholder">Layout</div> </div> <div class="card-content"> <h2>Nome do Layout</h2> <p>Descrição curta do layout.</p> <span class="badge">HTML + CSS</span> </div> </a>
3

Substitua as informações

Troque:

  • SEU-ARQUIVO.html → nome real do seu arquivo
  • Nome do Layout → título que aparece no card
  • Descrição curta... → uma frase explicando o layout
  • HTML + CSS → o que você quiser (badge)
4

Faça o deploy de novo

Salve as alterações e publique novamente no Netlify ou faça push no GitHub. Pronto!
